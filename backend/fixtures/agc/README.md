# 자동 게인 조절 시험 소리

기기가 녹음 음량을 스스로 조절하는지(자동 게인 조절) 확인하는 시험 소리다. 자동 게인 조절이 켜져 있으면 음량 지표를 믿을 수 없으므로, 앱 녹음 경로마다 한 번 확인한다.

- [`signals.json`](signals.json): 시험 소리의 정답값(구간, 음량). 서버 분석은 녹음을 이 값과 비교한다.
- [`generate.py`](generate.py): 정답값대로 WAV를 만든다. WAV는 저장소에 올리지 않는다.

## 1. 파일 만들기

Python 3.9 이상만 있으면 된다(추가 패키지 없음).

```bash
python3 backend/fixtures/agc/generate.py              # backend/fixtures/agc/ 에 만든다
python3 backend/fixtures/agc/generate.py --out 폴더     # 지정한 폴더에 만든다
```

| 파일 | 길이 | 내용 |
|---|---|---|
| `agc_steps.wav` | 23초 | 220 Hz 소리가 3초마다 6 dB씩 커진다(−45 → −9 dBFS, 7단계) |
| `agc_sustain.wav` | 32초 | 220 Hz 소리를 −21 dBFS로 30초 유지한다 |
| `agc_on_off.wav` | 22초 | 220 Hz 소리(−21 dBFS)를 1초 켜고 1초 끄기를 10번 되풀이한다 |

- 모두 모노, 16비트, 48000 Hz이고, 앞에 1초 무음이 있다.
- 음량(dBFS)은 20 × log₁₀(RMS(제곱평균제곱근 진폭))이다. 정현파의 진폭은 RMS의 √2배다.

## 2. 시험 방법

**준비**
- 조용한 방에서, 앱이 실제로 쓰는 입력 장치(유선 헤드셋 마이크)를 폰에 연결한다.
- 시험 소리는 다른 기기(PC 등)의 스피커로 재생한다. 재생 기기의 음량 효과(이퀄라이저, 음량 평준화)는 끈다.
- 마이크와 스피커의 거리와 재생 음량을 정하고, 시험이 끝날 때까지 바꾸지 않는다. 가장 큰 단계(`agc_steps.wav`의 마지막 3초)에서도 녹음이 찌그러지지 않을 정도로 맞춘다.

**파일마다**
1. 앱에서 `purpose=agc_test` 세션을 시작한다. 세션 등록의 `client_meta`에 재생할 파일 이름을 넣는다. 예: `{"agc_signal": "agc_steps"}`
2. 녹음을 시작하고, 시험 소리를 재생한다.
3. 재생이 끝나고 1초쯤 뒤 녹음을 멈춘다. 녹음 종류는 `agc_tone`이다.
4. 업로드하고 complete를 보낸다.

## 3. 판정

판정은 서버 분석이 한다. 기준 수치는 분석을 구현할 때 정한다.

| 파일 | 자동 게인 조절이 없을 때 | 자동 게인 조절이 있을 때 |
|---|---|---|
| `agc_steps.wav` | 녹음 음량도 단계마다 약 6 dB씩 오른다 | 단계 사이 차이가 6 dB보다 작아진다(특히 큰 단계에서) |
| `agc_sustain.wav` | 30초 동안 녹음 음량이 거의 일정하다 | 시간이 지나며 음량이 줄거나 늘어난다 |
| `agc_on_off.wav` | 켤 때마다 같은 음량으로 녹음된다 | 켠 직후가 크다가 줄어들거나, 무음 뒤에 음량이 달라진다 |
