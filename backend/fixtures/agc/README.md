# 자동 게인 조절 시험 소리

기기가 녹음 음량을 스스로 조절하는지(자동 게인 조절) 확인하는 시험 소리다. 자동 게인 조절이 켜져 있으면 음량 지표를 믿을 수 없으므로, 앱 녹음 경로마다 한 번 확인한다.

- [`signals.json`](signals.json): 시험 소리의 정답값(구간, 음량). 서버 분석은 녹음을 이 값과 비교한다.
- [`generate.py`](generate.py): 정답값대로 WAV를 만든다. WAV는 저장소에 올리지 않는다.

## 1. 파일 만들기

Python 3.9 이상만 있으면 된다(추가 패키지 없음).

```bash
python3 backend/fixtures/agc/generate.py              # backend/fixtures/agc/ 에 만든다
python3 backend/fixtures/agc/generate.py --out 폴더     # 지정한 폴더에 만든다
```

| 파일 | `agc_signal` | 길이 | 내용 |
|---|---|---|---|
| `agc_steps.wav` | `agc_steps` | 23초 | 220 Hz 소리가 3초마다 6 dB씩 커진다(−45 → −9 dBFS, 7단계) |
| `agc_hold.wav` | `agc_hold` | 32초 | 220 Hz 소리를 −21 dBFS로 30초 유지한다 |
| `agc_toggle.wav` | `agc_toggle` | 22초 | 220 Hz 소리(−21 dBFS)를 1초 켜고 1초 끄기를 10번 되풀이한다 |

- 모두 모노, 16비트, 48000 Hz이고, 앞에 1초 무음이 있다.
- 음량(dBFS)은 20 × log₁₀(RMS(제곱평균제곱근 진폭))이다. 정현파의 진폭은 RMS의 √2배다.

## 2. 시험 방법

**준비**
- 조용한 방에서, 앱이 실제로 쓰는 입력 장치(유선 헤드셋 마이크)를 폰에 연결한다.
- 시험 소리는 다른 기기(PC 등)의 스피커로 재생한다. 재생 기기의 음량 효과(이퀄라이저, 음량 평준화)는 끈다.
- 마이크와 스피커의 거리를 정하고, 시험이 끝날 때까지 바꾸지 않는다.

**재생 음량 맞추기(먼저)**
- `agc_steps.wav`의 가장 큰 단계(마지막 3초)를 재생하면서 녹음해 보고, 소리가 찌그러지지 않게 재생 음량을 먼저 맞춘다.
- 맞춘 재생 음량은 시험이 끝날 때까지 바꾸지 않는다.

**녹음**: 세션 하나에 녹음 3개
1. 앱에서 `purpose=agc_test` 세션을 시작한다.
2. 소리마다 녹음을 시작하고 재생한다. 재생이 끝나고 1초쯤 뒤 녹음을 멈춘다. 순서는 `agc_steps` → `agc_hold` → `agc_toggle`이다.
3. 녹음 3개를 `kind=agc_tone`으로 올린다. 녹음마다 `agc_signal`에 재생한 소리(위 표)를 적는다.
4. complete를 보낸다.

## 3. 판정

판정은 서버 분석(`backend/analysis/agc_check.py`)이 한다. 녹음 음량의 절대값은 재생 음량과 거리에 따라 달라지므로, 소리 안의 상대 변화만 본다. 기준 수치는 모두 초기값이다.

| 소리 | 자동 게인 조절이 없을 때 | 자동 게인 조절이 있을 때 | 의심으로 보는 기준 |
|---|---|---|---|
| `agc_steps` | 녹음 음량도 단계마다 약 6 dB씩 오른다 | 단계 사이 차이가 6 dB보다 작아진다(특히 큰 단계에서) | 단계 사이 차이가 6 ± 2 dB를 벗어남 |
| `agc_hold` | 30초 동안 녹음 음량이 거의 일정하다 | 시간이 지나며 음량이 줄거나 늘어난다 | 1초마다 잰 음량의 최대 − 최소가 2 dB 초과 |
| `agc_toggle` | 켤 때마다 같은 음량으로 녹음된다 | 켠 직후가 크다가 줄어들거나, 무음 뒤에 음량이 달라진다 | 켠 직후와 끝 쪽 차이 평균 2 dB 초과, 켤 때마다의 음량 차이 2 dB 초과, 끈 구간 음량이 앞 무음보다 6 dB 초과 |

- 음량은 녹음을 16 kHz로 바꾼 뒤 30 ms 프레임 음량(dBFS)의 중앙값으로 잰다. 잡음 바닥은 녹음 처음 0.5초다. 그래서 **녹음을 먼저 시작하고 재생한다.**
- 찌그러진 단계(표본이 최대 크기에 닿음)와 잡음에 묻힌 단계(잡음 바닥 + 10 dB 이하)는 빼고 본다. 비교할 단계 사이가 3개보다 적으면 판정 불가다. 찌그러짐이 나오면 재생 음량을 줄여 다시 녹음한다.
- 세 소리 중 하나라도 의심이면 "자동 게인 조절 의심", 녹음이 없거나 판정 불가인 소리가 있으면 "판정 불가", 셋 다 정상이면 "자동 게인 조절이 보이지 않는다"이다.
